## 目标

普通过程理论描述哪些有类型过程可以复合；资源敏感理论还必须说明成本如何复合、哪些重写保持
成本，以及语法估计何时在语义上成立。Ript 在 Lean 中显式表达这些义务。

总研究目标是构造一种可计算、机器可验证、单值化、高阶范畴化的资源受限信息过程理论，使
经典概率、量子过程、因果模型、计算、语义信息和热力学成为不同模型，并满足相应表示与完备性
定理。仓库持续朝完整目标推进；成熟度提示用于标记尚未证明的部分，而不是把目标缩小。

库围绕五项原则组织：

- 有序加法资源跟踪串行与并行预算；
- 可执行语法与基于商的证明模型分离；
- 解释必须证明类型、等式和资源界得到保持；
- 张量、复制、丢弃、凸性、因果性与热力学等能力相互独立表示；
- 定理声明只覆盖固定工具链中实际编译的声明。

Ript 是形式研究库，不是运行时估算器，也不是已经完成的物理信息理论。精确边界由
[研究状态](RESEARCH_STATUS.md)维护。

## 仓库包含什么

形式核心覆盖带成本范畴、可执行顺序与单子语法、解释、健全性、相对完备性和单子初始性。
具体有限模型覆盖确定性与随机通道、决策问题、全计算与偏计算、因果 DAG、热系统和有限量子通道。

高阶层把过程模型组织为双范畴，定义成本精确等价，研究行走局部化构造，并提供有界内部恒等
语义。有序加法资源变换连接使用不同资源代数的模型；这些纤维被封装成总双范畴，带有资源相等
的单子 2-胞腔、异质水平复合、交换律以及五边形/三角形协调。
[模型能力矩阵](reference/MODEL_MATRIX.md)只记录已经实现并编译的操作。

当前最高局部化层已经为每个 local mapping category 给出完整 generated-hammock 呈示、到实际局部化
目标的直接范畴 nerve 等价、显式单纯同伦逆，以及终止且保持语义的 administrative reduction。
这是经审计的项目内 Dwyer--Kan core；它还不是与经典 reduced 任意网格 hammock 的比较，也不是
标准全局 Rezk 弱等价定理。

## 信任模型

Ript 禁止：

- `sorry`、`admit` 等证明占位符；
- 用项目自定义公理代替未完成研究；
- 编译器信任逃逸和不安全库声明；
- 审计旗舰定理中未记录的假设。

质量门禁锁定 Lean 与 Mathlib 修订版本，把警告视为错误，执行代表性模型，检查源码策略与文档化
假设，并完成全量构建。选定定理的精确假设见[公理清单](reference/AXIOMS.md)，开放陈述见
[猜想登记册](reference/CONJECTURES.md)。

内核检查证明声明可由所列假设推出；它本身不能证明形式模型就是某个物理系统的正确经验模型。

## 成熟度与稳定性

Ript 是早期研究软件：

- Lake 包版本为 `0.1.0`；
- 尚无稳定公共 API 或带标签兼容承诺；
- 尚无存档 DOI；
- 随研究推进，定理名与模块边界可能改变。

可复现使用应锁定完整 commit SHA；研究产物应同时引用仓库与该 SHA。

## 许可

项目尚未选择开源许可证。源码公开本身并不授予复制、修改或再分发权；若未来采用许可证，本段将
由正式许可说明替代。
