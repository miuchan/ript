# Ript 形式化蓝图

[English](../../en/reference/BLUEPRINT.md) · [简体中文](BLUEPRINT.md) ·

本蓝图只记录由 Lean 内核检查的实现状态。允许的状态为 `DEFINED`、
`STATEMENT_FORMALIZED`、`PROVED`、`BLOCKED` 和 `OPEN_RESEARCH`。
根目录的[机器规范蓝图](../../../BLUEPRINT.md)保存每个声明的完整 Lean 类型、依赖、公理足迹和
源文件；本地化版本保持相同阶段边界和定理族索引。

## 总目标

构造一种可计算、机器可验证、单值化、高阶范畴化的资源受限信息过程理论，使经典概率、量子过程、
因果模型、计算、语义信息和热力学成为不同模型，并证明相应表示定理与完备性定理。下表的局部
`PROVED` 不等于该全局目标已经完成。

## 依赖主干

```text
资源代数 → 带成本过程 → 预算/过滤/资源变换
      ↓
顺序语法 → 解释 → 健全性 → 项模型 → 相对完备性/严格初始性/路径表示
      ↓
单子语法 → 并行成本 → 单子解释/健全性 → 自由模型初始性
      ↓
有限函数 / 有限随机 / 决策 / 计算 / 因果 / 热 / 量子模型
      ↓
资源模型双范畴 → 异质总双范畴 → 普通与高阶局部化
      ↓
内部单值语法 → 群胚/商/骨架 → Yoneda → 单纯神经 → 分类图
```

公共单子语法现在还可沿 `φ : R →+o S` 推前成本；线型与生成元保持不变，表达式翻译可逆，异质
解释等价于普通推前解释，自由模型精确实现 `φ` 翻译后的预算。

## 旗舰定理族

### 核心、语法与完备性

- `Ript.Resource`：预算恒等/复合、过滤–成本往返、资源重索引；
- `Ript.Semantics`：`eval_cost_le`、顺序与单子健全性、项模型相对完备性、自由模型预算精确性；
- `SequentialNormalForm`：任意顺序签名的项范畴–路径范畴等价、精确成本保持、路径像和路径忠实完备性；
- `SequentialFree/ResourceChangingSequentialFree`：解释–自由源资源函子分类、可收缩严格延拓类型、自由提升和成本界；
- `Ript.Semantics.Free`：生成元一致、成本不增、严格自由提升唯一性；
- `ResourceChangingMonoidalInterpretation`：异质解释表示等价、翻译后求值界和自由模型完备性。
- `CommonBitRealizations`：六种模型特定解释、原生计算资源翻译和 `sixModelFlipAgreement`。
- `CompositionalBitRealizations`：两步复合恢复恒等，以及 `sixModelCompositionAgreement`。
- `CompositionalBitCompleteness`：规范形、精确像表示和 `sixModelSemanticCompleteness`。
- `OperationalErasureRealizations`：六模型擦除、干预、价值损失和 `sixModelErasureAgreement`。
- `DiamondBitTheory/Realizations`：非薄精确像、六模型路径分离、语义完备性及六个规范异质自由提升。
- `ParallelBitRealizations/HigherModels`：六模型并行行为、完整 Kraus 量子目标、任意乘积密度矩阵上的 Pauli-X 张量、精确计算资源相加，以及带已检查资源映射的总双范畴 1-胞腔。
- `QubitInstrument/InstrumentSyntax`：相干 plus 态测量与反馈、三个历史概率为 `1/2、1/2、0` 且预算为 `2` 的第一类递归树、历史分支表示，以及一/二单位资源自由提升。
- `NoisyBitRealizations`：六模型共享 `3/4–1/4` 噪声边界，随机单位量子通道保留 plus 相干而测量–制备不保留，随机化计算资源与语义风险/价值精确。
- `Syntax.Branching/AdaptiveNoiseRealizations`：任意定深二叉树的可执行历史、正分支表规范形、精确成本、表示和观察完备性；两生成元自适应树具有四个精确分支、六模型表示、量子相干区分与完备性区分见证。
- `Syntax.DependentBranching/Examples.DependentBranching`：变深且每生成元具有不同有限结果类型的树、显式历史等价、记录表表示/完备性和保守二叉嵌入；`Bool`/`Fin 3` 实例有五个不同长度历史。
- `DependentBranchingRealization`：任意有限正依赖规范形的六模型通用表示、路径成本/历史长度资源界、全支撑因果忠实性、联合等式反射完备性，以及外部给定兼容目标平衡态的唯一热提升。
- `Syntax.DependentBranching.Free`：分支代数与同态范畴、初始树代数、唯一自由解释、所有代数中的健全/完备等式、顺序嫁接幺半群及高度/预算数值 fold。
- `Syntax.DependentBranching.Monoidal`：分支模型代数的选定有限积和笛卡尔对称单子协调，乘积 fold 精确配对两个模型解释，树项模型乘积联合完备。
- `Syntax.DependentBranching.Parallel`：树级显式双通道、独立随机信道分解、交换对称、资源相加、共享阶段顺序嫁接、严格交换律与并行完备性。

### 概率、决策与语义信息

- `FiniteStochastic`：恒等、Chapman–Kolmogorov 复合、张量、Dirac 忠实性、凸混合与因果丢弃；
- Kleisli 与 `Stoch` 桥：双向表示、函子性、忠实性与张量保持；
- 决策：Blackwell 数据处理、确定性纤维判据、完整有限随机逆定理、有理分离、资源语义价值，以及全任务精确数值剖面对 Blackwell 等价的完备性；单任务标量不完备已有布尔见证。

### 计算、因果、热与量子

- 计算：多维资源界的声音性、全计算/偏计算复合与张量；
- 因果：DAG 联合分布归一化、软/随机/硬机制替换、约化程序规范形、模型/信道表示与 `FinStoch` 完备语义；
- 热：Gibbs 保持通道的内在像/唯一提升、KL 数据处理、自由能/相关分解、Landauer 界、浴与电池见证；
- 量子：Kraus 正性/保迹、操作与有限仪器、归一化 Born 概率和后验态、串行/并行仪器律、经典记录通道表示、张量交换、完整对称单子协调律、完全正性、迹丢弃和经典随机忠实嵌入。

### 高阶与单值层

- 固定资源与总资源模型双范畴的 2-胞腔复合、交换、结合子、单位子、五边形与三角形；
- 成本精确等价的预算保持/反射；
- 普通同伦局部化，以及保留非可逆 2-胞腔的参数化行走测试；
- 内部恒等–等价对应、对象完备化、Yoneda 全忠实、Kan 神经、严格 Segal 和分类图匹配纤维化。

每个具体声明的 Lean 类型、`Classical.choice` 边界和源路径见

## 未完成边界

真正的跨模型比较；完整资源过程双范畴到内部单值或标准 complete-Segal 语义的泛局部化。任何这些
目标都没有被隐藏为 Lean 公理或占位定理。
