# アーキテクチャ

[English](../en/ARCHITECTURE.md) · [简体中文](../zh-CN/ARCHITECTURE.md) ·
[日本語](ARCHITECTURE.md) · [Esperanto](../eo/ARCHITECTURE.md)

Ript は、実行可能な有限モデルが商、測度論、高次圏、内部ユニバレント機構に依存しないように
構成されています。各層は下位インターフェースを利用できますが、逆向きの import はレビューと
ルートモジュール構造で禁止します。

## 依存方向

```text
資源代数
   ↓
コスト付き過程インターフェース
   ↓
資源の再添字付けと異種モデル写像
   ↓
実行可能構文 ──→ 意味論と項モデル
   ↓                    ↓
有限モデル ─────→ 一般意味論ブリッジ
   ↓                    ↓
モデル双圏と局所化
   ↓
内部ユニバレント解釈
```

最後の層は深い構文を解釈します。Lean の等号を変更せず、上位層へユニバレンスを追加しません。

## 資源と過程のコア

`Ript/Resource/` は過程の尺度となる代数を定義します。

- 順序付き加法資源
- 予算と予算付き射
- 単調な移送と順序付き加法による資源代数変更
- コスト誘導・到達可能フィルトレーション
- 並列予算則

`Ript/Core/` はこの代数を圏と能力へ接続します。

- 過程コストと直列合成の劣加法性
- 任意能力としての並列コスト、構造コスト、凸性、複製、破棄
- シミュレーションと単調写像
- 余分な構造を推論しない能力インターフェース

テンソルは複製や破棄を意味しません。凸性、因果構造、熱構造も明示的な能力です。

## 構文と意味論

`Ript/Syntax/` は型付き生構文、コスト計算、明示的導出を含み、生構文は実行可能です。

`Ript/Semantics/` は次を含みます。

- コスト付き圏への解釈
- 評価とコスト健全性
- 等式健全性
- 商項モデルと相対完全性
- 対称モノイダル意味論と初期性
- 順序付き加法資源変更を横断する共通構文解釈、可逆な式変換、厳密な押し出しコスト自由モデル完全性

商は証明層に限定されます。有限構文だけを評価する利用者は商機構を実行しません。

## 具体モデル

`Ript/Models/` 以下は孤立したデータ構造ではなく意味論的インスタンスを実装します。

- `FiniteFunction`：決定論的基準と明示的なデカルト複製・破棄
- `FiniteStochastic`：正規化された厳密有理確率チャネル、合成、テンソル、凸混合、複製、破棄
- `FiniteDistribution`：有限分布モナドと Kleisli 表現
- 確率モジュール：有限厳密チャネルから Mathlib `Stoch` へのブリッジ
- 意思決定モジュール：Blackwell 比較、厳密リスク、資源境界、分離証明書
- 計算モジュール：形式的ステップ/問い合わせ/記憶/ゲート量と実時間の分離
- 因果モジュール：有限トポロジカル順序 DAG と hard intervention
- 熱モジュール：厳密な操作チャネルと実数値解析熱力学の分離
- 量子モジュール：有限 Kraus 族を用い、チャネル化前に正値性とトレース保存を証明

[モデル能力行列](reference/MODEL_MATRIX.md)が、各モデルの任意構造についての正式記録です。

## 高次構成

`Ript/Higher/` は完全な過程モデルを双圏として束ねます。

- 0-セル：資源で添字付けられた対称モノイダル過程モデル
- 1-セル：資源を増加させない強組紐モノイダル関手
- 2-セル：モノイダル自然変換

固定資源双圏は、より広い実装済み層の一つのファイバーです。`ResourceChangeModelHom` は順序付き
加法写像 `R →+o S` 上で `R` モデルを `S` モデルへ接続します。異種 1-セルは資源写像とともに
合成し、検査済み予算を移送し、固定資源写像ごとにモノイダル 2-セルの局所圏を持ちます。
`ResourceModel`、`ResourceModelHom`、`ResourceModelTransformation` はそれぞれ対象、1-セル、
2-セルを束ね、異種 whiskering、水平・垂直合成、交換則、結合子、単位子、五角形、三角形を持つ
全双圏を形成します。

双圏同値だけから数値コストの等号は導きません。`CostExactModelEquivalence` が反映を明示します。

局所化は強さごとに分離されています。

- モデルホモトピー圏の通常の Gabriel–Zisman 局所化
- 逆射の自由添加を検査する walking 例
- 独立に定義された厳密な双圏的普遍性述語
- 未証明の整合性や本質的全射性を公理で代用しない方針

## 内部ユニバレント解釈

`Ript/Univalent/` は通常の過程理論の下流で、深いインターフェース符号、内部構造同値と恒等の
別構文、亜群解釈、0-切断対象商、1-切断骨格、表現可能前層、Yoneda 意味論、単体神経、分類図を
定義します。

これは Lean の外部 HoTT ではありません。Ript は大域的な `Equiv α β → α = β` を仮定せず、
主張は内部構文と正確にコンパイルされた圏論インターフェースに限定されます。

## 実行可能境界と解析境界

有限コアは自然数資源ベクトル、有限型、非負有理確率、決定可能な有限最小値、明示的証人などの
厳密データを使います。実解析、測度論、商、選択された代表元、行列証明は意味論層にあり、
非計算的な場合があります。有限対象についての定理であっても、API と仮定を確認せず実行可能とは
呼びません。

## 品質アーキテクチャ

`scripts/quality-gate.sh` は CI と一致するローカル入口です。証明穴、独自公理、信頼回避、unsafe
宣言、広すぎる import、暗黙識別子、ルート import 漏れ、警告、lint、実行例、公理 allowlist、
Markdown 構造を検査します。ワークフローは固定 action と読み取り専用権限を使います。
変更方針は[コントリビューションガイド](CONTRIBUTING.md)を参照してください。
