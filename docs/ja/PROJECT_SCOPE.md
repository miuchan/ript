# プロジェクトの範囲と信頼境界

[English](../en/PROJECT_SCOPE.md) · [简体中文](../zh-CN/PROJECT_SCOPE.md) ·
[日本語](PROJECT_SCOPE.md) · [Esperanto](../eo/PROJECT_SCOPE.md)

このページでは、Ript が何を形式化し、主張をどう検査し、どの制限を持つかを説明します。

## 目的

通常の過程理論は、どの型付き過程が合成できるかを記述します。資源感応的理論ではさらに、
コストの合成、コストを保存する書き換え、構文的見積もりが意味論的に正しい条件を指定する必要が
あります。Ript はこれらの義務を Lean 上で明示します。

研究目標は、計算可能・機械検証可能・ユニバレント・高次圏論的な資源制約付き情報過程理論を
構成し、古典確率、量子過程、因果モデル、計算、意味情報、熱力学を異なるモデルとして実現し、
表現定理と完全性定理を証明することです。成熟度表示は未証明部分を示すもので、目標を縮小しません。

原則は次の五つです。

- 順序付き加法資源で直列・並列予算を追跡する
- 実行可能構文と商に基づく証明モデルを分離する
- 解釈は型、等式、資源境界の保存を証明する
- テンソル、複製、破棄、凸性、因果性、熱力学を独立能力として表す
- 固定ツールチェーンでコンパイルされる宣言だけを定理として主張する

Ript は形式研究ライブラリであり、実時間推定器でも完成済み物理情報理論でもありません。境界は
[研究状況](RESEARCH_STATUS.md)に記録します。

## リポジトリの内容

コアはコスト付き圏、実行可能な逐次・モノイダル構文、解釈、健全性、相対完全性、モノイダル
初期性を扱います。有限モデルは決定論・確率チャネル、意思決定、全計算・部分計算、因果 DAG、
熱系、有限量子チャネルを含みます。

高次層はモデル双圏、コスト厳密同値、walking 局所化、限定的内部恒等意味論を提供します。
異なる資源代数を順序付き加法写像で接続し、資源写像が等しいモノイダル 2-セル、異種水平合成、
交換則、五角形・三角形整合性を持つ全双圏に束ねます。実装済み操作は
[モデル能力行列](reference/MODEL_MATRIX.md)だけに記載します。

## 信頼モデル

次を禁止します。

- `sorry` や `admit` などの証明穴
- 未完の研究を代用するプロジェクト独自公理
- コンパイラ信頼回避と unsafe なライブラリ宣言
- 監査対象の主要定理における未記録の仮定

品質ゲートは Lean/Mathlib を固定し、警告をエラーとして扱い、代表モデルを実行し、ソース方針と
仮定文書を検査し、完全ビルドを行います。仮定は[公理一覧](reference/AXIOMS.md)、未証明命題は
[予想台帳](reference/CONJECTURES.md)にあります。

カーネル検査は、宣言が記載された仮定から従うことを保証します。物理系の経験モデルとして正しい
ことまでは保証しません。

## 成熟度と安定性

- Lake パッケージ版は `0.1.0`
- 安定公開 API やタグ付き互換性保証は未提供
- アーカイブ DOI は未取得
- 研究の進行により定理名とモジュール境界は変更され得る

再現には完全な commit SHA を固定し、成果物でリポジトリと SHA を引用してください。

## ライセンス

オープンソースライセンスはまだ選択されていません。ソース公開だけでは複製、変更、再配布の許可を
与えません。採用時に正式な記述へ置き換えます。
